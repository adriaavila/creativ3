# allok / De problema a sistema.

Concept proposal, started 28 October and packaged 29 October 2026. Not an approved replacement for the live brand.

Positioning: an AI-native design and software studio that turns operational problems into working systems. LATAM first, international craft, founder-led accountability.
Promise: De problema a sistema.
Essence: all systems OK. Intelligence is useful when the operation works.

Logo: custom lowercase geometric wordmark. The letter o becomes a readable open loop with a closing dot. The loop is also the standalone mark. Calm continuous strokes, clear spacing and a recognizable silhouette. The identity is stable and monochrome; live operational states move into separate UI status indicators. This deliberately changes the existing requirement that every logo encode a current product state, and needs Adrian's brand decision before implementation.

Palette: Ink #0B0D0E, Cloud #F7F8F8, Electric Blue #315CFF, Steel #697278. Blue is the brand field, not a live status. Real statuses retain the existing accessible state tokens. No decorative green status dots.
Type: Geist. Display 500/600 with -0.05em maximum tracking; body 400/500. Logo is custom vector geometry, independent of fonts.
Graphic system: the open loop, a closing dot and a continuous path. Crops of the same geometry create visual rhythm. Never a generic AI sparkle, robot or chrome blob.
Voice: short Spanish, tú, concrete work and outcomes. 'De problema a sistema.' 'Diseño, software e IA.' 'Cuéntanos qué necesitas.' No claims of being #1 or guarantees of ranking.
Image direction: original product captures and close-ups of real work. Generated application boards are concept presentations, not evidence of production outcomes.

Logo rules: one mark per lockup, preserve proportions, clear space equal to the o's internal radius, wordmark minimum width 96px, mark minimum 20px. Test 16px separately before favicon release. White on ink/blue, ink on Cloud. No gradients inside the logo, no shadows, no rotation, no replacing the o with a solid dot.

Existing website directions A/B/C remain unselected. The ambient open C tab is not an approval. This brand proposal is a separate decision.
